# LinxCAD desktop

Download and install: **[LinxCAD-win-Setup.exe](https://github.com/ermjohnnyhere/linxcad-releases/releases/latest/download/LinxCAD-win-Setup.exe)**

1. Run the file you downloaded. It installs for your Windows account only and does not need an administrator.
2. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.
3. Open LinxCAD from the Start menu or the desktop shortcut, then enter the community code your administrator gave you.

LinxCAD keeps itself up to date. New versions download quietly in the background and install the next time you close the app.

This repository only holds the current release of the installer. It does not contain source code.
